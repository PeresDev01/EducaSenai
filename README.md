## ✨ Sobre o Projeto

O **EducaSenai** é uma plataforma de reforço escolar voltada para **estudantes do Ensino Técnico**, desenvolvida para ajudar na superação das maiores dificuldades acadêmicas.

A plataforma proporciona uma experiência **personalizada e interativa**, permitindo que cada aluno escolha as disciplinas em que precisa de mais apoio.

* **Para Estudantes:** Acesso a conteúdos exclusivos, exercícios, vídeos explicativos e atividades gamificadas para reforçar o aprendizado.
* **Para Professores/Mentores:** Recursos de acompanhamento de desempenho e ferramentas de apoio ao ensino direcionado.

---

## 🚀 Funcionalidades Principais

### Para Estudantes (App Mobile)

* **👤 Perfil do Estudante:** Gerencie suas informações e acompanhe seu progresso nas disciplinas.
* **📚 Materiais Interativos:** Acesso a conteúdos teóricos, vídeos e exercícios de fixação.
* **🎮 Gamificação:** Recursos lúdicos para aumentar a motivação e engajamento.
* **📈 Relatórios de Desempenho:** Feedback sobre evolução em cada disciplina.

### Para Professores/Mentores (Sistema Web)

* **🗂️ Acompanhamento de Turmas:** Visualize o desempenho dos alunos e identifique dificuldades recorrentes.
* **📑 Upload de Conteúdo:** Disponibilize materiais, exercícios e atividades complementares.
* **⚙️ Personalização:** Configure trilhas de aprendizado para diferentes perfis de alunos.

## 🛠️ Tecnologias Utilizadas

* **Backend:** Java 21 com Spring Boot Framework
* **Frontend (Web/Mobile):** React e React Native
* **Banco de Dados:** HeidiSQL
* **Controle de Versão:** Git e GitHub
